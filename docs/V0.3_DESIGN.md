# V0.3 界面一致性与图标来源

核查日期：2026-09-20。设计依据保存在开发文档中，不增加主页面说明文字。

## 图标来源

V0.1、V0.2 的应用操作图标调用 `androidx.compose.material.icons`，来自 Google Material Icons，**不是静听独家原创**。官方以 Apache License 2.0 发布，可用于应用。[Google Material Icons 仓库与许可说明](https://github.com/google/material-design-icons)

V0.3 新增 `ui/JingTingIcons.kt`：每条矢量路径为本项目直接编写，没有复制 Material 图标路径。24 dp 网格、1.7 单位圆端线、圆角连接、单一前景色，统一覆盖媒体库、集合、播放控制、定时、操作菜单和无封面占位图。可在源文件中直接修改。播放三角形、时钟、加号等属于常见操作语义，不据此主张这些形状在全球唯一，亦没有做商标检索。

桌面和通知图标在 `res/drawable/ic_app.xml`、`ic_notification.xml` 中重新绘制。标志由包围声纹的开放圆弧和三条圆端声纹构成，使用与页面一致的暖黑、琥珀色；通知使用同一几何结构的单色版本，交由系统着色。

AndroidX Material 3 控件内部的勾选符、下拉箭头等仍由组件库提供，系统文件选择器、系统媒体通知等也有系统绘制的元素；本版没有把这些描述为本项目原创。依赖和许可说明见仓库根目录 `THIRD_PARTY_NOTICES.md`。

## 修正进入页面后的颜色变化

核查 V0.2 源码，主题只覆盖了部分 `darkColorScheme` 参数；对话框、菜单及较高层容器还可能使用未覆盖的默认颜色。Material 3 使用不同的 surface container 角色表达容器层级。[Android ColorScheme API](https://developer.android.com/reference/kotlin/androidx/compose/material3/ColorScheme)

V0.3 将 `NightPalette`、完整 `NightColorScheme` 和 `NightTheme` 放在独立文件中，明确赋值当前锁定的 Material 3 1.3.2 支持的全部颜色角色，包括 primary/secondary/tertiary 及其反衬色、所有 surface container、错误提示和遮罩。页面、菜单、播放器面板、弹窗、输入框、选择控件和系统启动窗口共享暖黑体系，不随壁纸动态换色。

| 用途 | 颜色 |
|---|---|
| 页面背景、系统栏 | `#100E0C` |
| 低层容器 | `#171411` |
| 普通卡片、播放器 | `#1C1916` |
| 对话框等较高层容器 | `#26211D` |
| 最高层容器 | `#302A24` |
| 主要文字 | `#D8D0C4` |
| 次要文字 | `#B6AEA2` |
| 操作强调 | `#C6A477` |
| 选中背景 | `#3A3025` |
| 错误文字 | `#D7A193` |

强调色用于可操作元素与选中状态，不铺成大面积亮色背景。封面仍保留媒体原图便于识别。本版不额外宣称颜色能够改善睡眠，夜间颜色调研及证据边界沿用 `V0.2_RESEARCH.md`。

## 验证边界

静态验证可确认应用页面引用统一主题、没有剩余 Material Icons API 调用、桌面与通知矢量资源已替换。实际弹窗、选择工具栏、播放器、定时任务界面需要在最终 APK 上检查；设备与截图验证结果统一记录在 `V0.3_TEST_REPORT.md`，不能用源文件替代设备结果。系统权限弹窗、系统文件选择器及键盘外观受系统和用户设置控制。
