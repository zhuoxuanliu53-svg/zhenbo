# 枕波 V0.5

新名称“枕波”：听着声音入睡，声音像小波纹。桌面标志以暖金月牙和波线组成，为本项目直接绘制矢量路径；不声称名称或常见几何形状全球唯一。

| 反馈 | 本版实施与验收 |
|---|---|
| 集合长按上下拖动 | 三列集合网格长按进入编辑并拿起文件，可跨行移动；触及上下边缘自动滚动；松手持久保存，取消手势恢复。验证向下、向上、跨屏、退出再进入。 |
| 刷新后删除项消失 | 系统媒体查询排除 pending／回收站，核对可读性；本地导入重新检查。媒体库、集合和添加文件统一隐藏不可访问项，已连接队列移除相应项。隐藏保留私有关系供恢复授权或文件恢复使用，不展示失效索引卡片。 |
| 长按编辑 | 媒体库长按选中并进入批量编辑；集合内容长按选中且可拖动；集合卡片长按管理；添加文件长按选择；播放器封面／迷你播放器长按重命名；播放任务长按编辑。保留可见按钮及辅助功能操作。 |
| 简洁动画 | 页面和集合详情短淡入淡出、轻位移；网格稳定 ID 的条目换位动画；拖动项轻微抬起。使用 Compose 动画系统，遵循系统动画缩放设置。 |
| 三列图库 | 媒体库、集合内容、添加文件三列正方形封面，下面两行文件名，时长叠在封面右下角。虚拟化仅组合可见条目，保留搜索、筛选和编号选择。 |
| 更名和图标 | 新应用名枕波、月牙波线矢量标志、自适应与单色图标。保持包名、签名、私有数据库及原导出目录，旧版可直接覆盖升级。 |

## 升级与边界

版本 0.5.0、versionCode 5，Room schema 仍为 3。本次不需要变更已保存的数据结构。内部包名继续使用 `app.jingting.localplayer`，保留 `Music/静听/` 导出目录以免改名造成路径分裂；旧文件不重命名、不移动。安装后名称显示枕波。

验证新增手势、图库布局、删除与恢复、品牌资源，并回归视频后台播放、集合与批量操作、计时、导出和质量规则。实际设备证据与尚未验证范围写入 V0.5 测试报告。

## 官方技术依据

- [Lazy grids、稳定 key 与条目动画](https://developer.android.com/develop/ui/compose/lists)：使用 LazyVerticalGrid；不把全部媒体一次放入可滚动 Column。
- [MediaStore 媒体字段](https://developer.android.com/reference/android/provider/MediaStore.MediaColumns)：排除 IS_PENDING 与 IS_TRASHED。
- [Android 14 部分媒体权限](https://developer.android.com/about/versions/14/changes/partial-photo-video-access)：访问范围会变化，重新查询系统事实；不把失去访问权直接等同于源文件被永久删除。
