# 枕波 V1.0 验证记录

验证日期：2026-09-23。版本 1.0.0（versionCode 100），最低 Android 10，compileSdk 37 / targetSdk 36。发布对象为 Android APK；HarmonyOS 原生版不包含在内。

## 结果

- Release 与 Android instrumentation 构建、13 项 JVM 单元测试和 Release / Debug Lint 均通过。Lint 为 0 error；构建仍报告 Media3 已弃用 API 与 Gradle 未来兼容性提示。
- Android 17（API 37）模拟器完整设备回归 71 项：69 项通过，2 项按设计跳过。跳过项要求外部卸载重装产物或显式升级阶段，已由专用验证脚本覆盖。
- 集合交互回归 8/8 通过，覆盖静止长按选择、拖动换序、长列表边缘滚动、取消拖动、页面返回和刷新。损坏媒体跳过、锁屏定时开始、睡眠停止及导出取消均在最终 Release APK 上验证。
- V0.5 覆盖升级通过；集合顺序、显示名称、定时、导出记录、私有文件和播放快照均保留。
- 卸载重装通过：公开 `Music/静听/` 中的合成导出文件卸载前后 SHA-256 一致（`29fc3510e5862552a5e2b1cd94211987fbe67d9ac2cd00cc86079a474f833109`），重新安装后可被媒体库重新发现。
- 设备实际导出的拼接文件回读验证通过：48 kHz、双声道、5.023 秒；左右声道分别保留 440 Hz 与 880 Hz 测试音，单声道片段复制到左右声道，音频顺序正确。
- 最终 APK 审计通过：Release 不可调试、16 KB ZIP 对齐、禁用云备份、不含 INTERNET / 网络状态 / 录音 / 全盘文件权限，APK 内含 7 份第三方许可文件。完整设备回归在飞行模式下运行。

完整 instrumentation 输出、覆盖升级和卸载重装的机器可读结果保存在 `artifacts/`；该目录不放进源码仓库，发布版本只附 APK、源码压缩包与校验文件。

## 未验证范围

这次发行周期没有连接目标用户真机。两小时连续锁屏播放、蓝牙／有线耳机拔出、厂商省电策略、实际耗电和大规模图库性能尚未在目标手机验证。Android 10、13、14、16 的本次发行覆盖未重跑；API 37 模拟器结果不代表所有手机兼容。首次构建源码需要联网下载开发依赖；安装后的应用没有联网权限。
