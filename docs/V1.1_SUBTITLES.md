# V1.1 字幕测试版

## 使用

1. 在媒体库或集合中选择视频，打开“导出音频”或“拼接音频”。
2. 打开“同时导出字幕”，为每段选择内置文本字幕、识别画面或无字幕。仅一条可用内置字幕时自动选中；多条时请选择需要的语言。
3. 画面识别可以拖动预览进度、拖拽框选字幕区域，并先识别当前画面。默认框选底部三分之一。支持中、英、日横排文字，不进行翻译或语音识别。
4. 首次选择手机上的保存文件夹。音频和 UTF-8 SRT 使用同名文件，重名时增加后缀，不覆盖原文件。关闭字幕时仍保存到 Music/静听/。
5. 在播放页查看字幕，或打开“纯播放页”。可以调整字号、前后跳转、暂停；默认跟随系统熄屏，“保持亮屏”为可选项。

纯播放页由用户主动打开，可显示在系统锁屏之上，但不解除系统密码锁。不自动亮屏，也不是息屏显示。厂商系统可能限制再次亮屏时显示该页；可从通知入口主动进入。

## 字幕文件与重试

- 字幕同时关联源视频和导出音频，拼接文件采用独立时间线。
- 字幕失败时若音频已经保存，任务明确提示并提供“重试字幕”；重试不重新转换或覆盖音频。
- 卸载后授权目录中的音频和 SRT 保留，应用内集合和字幕关联会清除。重装后可在播放页选择“从文件夹匹配字幕”；未匹配或同名歧义时使用“导入字幕”手动指定。
- 播放页“校准”可提前或延后字幕，正值表示延后，仅影响本应用播放显示。
- 内置文本字幕验收格式为 MKV SubRip、ASS/SSA，MP4 tx3g、WebVTT。SRT 不保存字体、颜色、动画、位置。PGS/VobSub 等图片字幕暂不支持。
- OCR 适合清晰固定字幕。小字、遮挡、滚动、花字、快速闪现可能漏字或错字；识别结果不是人工校对稿。

## 离线与模型

PP-OCRv5 mobile 检测和识别 ONNX 模型随 APK 内置，首次使用不下载。模型、字典的来源和 SHA256 见 `app/src/main/assets/ocr/models.json`。模型共约 21.4 MB，APK 还包含 ONNX 原生运行库，实际安装包增量以测试报告为准。

ONNX Runtime 1.22.0，显式禁用遥测；应用仍不声明 INTERNET 或 ACCESS_NETWORK_STATE。运行时不会获取远程模型、上传媒体、文字或识别结果。依赖与模型许可证随 APK 和源码分发。

## 构建与验证

沿用根目录构建说明；运行 `tools/build.ps1`。模型文件已随源码提供，无需在手机端配置 Python 或 Google 服务。合成字幕测试素材由 `tools/generate_subtitle_fixtures.py` 生成。

关键验证包括 `SubtitleTest`（SRT、重叠、时间映射、空白间隔）与 `V11SubtitleTest`（离线 OCR、四类内置字幕、连续解码、配对导出、字幕重试、拼接、数据库迁移和锁屏）。模拟器验证不能替代目标手机的厂商锁屏与电池策略测试。
