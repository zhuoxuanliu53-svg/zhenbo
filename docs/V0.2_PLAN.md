# 静听 V0.2

基于实际使用反馈调整界面，保留离线播放与导出能力，直接覆盖 V0.1 安装升级。

| 反馈 | 本版实现 |
|---|---|
| 视频无法辨认 | 媒体库、集合、迷你播放器和完整播放器展示本地视频缩略图；音频优先内嵌封面。异步读取、有限缓存，失败用占位图 |
| 文案冗余 | 去掉首页口号、离线徽标、实现细节和宣传式空状态。权限与失败保留必要操作提示 |
| 提取像下载 | 视频行直接显示「提取音频」文字按钮；更多菜单也提供同名操作 |
| 集合编辑绕路 | 集合内打开添加文件面板，直接多选添加；支持单项及批量移除、上下排序、改显示名、提取、选多音频拼接、加入其他集合 |
| 导航过重 | 底部仅「媒体库／集合」；顶部时钟打开定时与导出，齿轮打开设置；返回保留集合位置 |
| 播放模式不清 | 「播完停止／单曲循环／列表循环／随机播放」，改为显式选择并各附一句行为说明；点击集合中某项保留完整集合队列 |
| 重装文件冲突疑问 | 导出仍新建 MediaStore 文件，不覆盖已有音频；说明收在设置详情。覆盖升级迁移保留集合、顺序、定时等数据 |
| 夜间配色 | 近黑暖灰背景、柔和暖白文字、少量琥珀色，避免高亮大面积；不强制修改亮度、不宣称助眠功效 |

本版「重命名」仅改变静听显示名称，不更名或移动源文件。移出集合也不删除源文件。系统文件管理器仍可处理原始文件。

数据升级：Room 1→2 新增独立别名表；不使用清空数据库式迁移。包名和签名沿用，versionCode 从 1 到 2。

验证重点：旧版数据库迁移、别名不会被扫描覆盖、同名导出不覆盖、真实视频和音频封面、集合内完整编辑流程、导航与播放方式可发现性。继续运行背景播放、睡眠、定时及导出回归；新版本设备结果另记，不继承为真机通过。

配色与存储依据见 [调研记录](V0.2_RESEARCH.md)，实施结果见 [V0.2 测试报告](V0.2_TEST_REPORT.md)。
