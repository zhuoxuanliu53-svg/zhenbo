# 枕波隐私说明

更新日期：2026-09-27。适用于枕波 Android V1.1.0 测试版。

枕波只在设备本地工作。APK 不声明 INTERNET 或 ACCESS_NETWORK_STATE，不包含账号、广告、统计、远程封面或崩溃上传组件。

媒体读取权限用于扫描用户授权的本地音视频。视频仅部分授权时，只展示系统允许访问的结果；拒绝一类权限不会阻止另一类已授权媒体的使用。手动选择文件保留持久读取授权，但源文件移动、删除或撤销授权仍会使条目失效。

媒体索引、显示名称、集合、队列、播放位置、定时配置和导出状态保存在应用私有数据库与 DataStore。计时状态还包括来源、播放模式、剩余时长截止值及完成／取消结果；定时使用当前队列时保存当时的媒体 ID 顺序。设备重启会取消计时，未来定时任务重新登记。缩略图仅从本地媒体解码并有限缓存在内存中。应用关闭系统云备份及设备迁移备份。应用不记录媒体文件名、URI、集合或异常内容到日志；Media3 日志关闭。系统自身可能记录诊断信息，应用无法控制整个操作系统的日志行为。

音频提取和拼接完全在本机进行。导出结果按实际路径保存为 M4A 或 WAV，位置为公共 `Music/静听/` 目录；每次创建新文件，不覆盖原始媒体或已有导出。其他获媒体权限的应用可以读取，设备上其他同步工具也可能按自己的设置处理这些文件。枕波不主动上传。卸载枕波会清除私有数据，但不会删除公共目录内的导出文件或原始媒体；重新安装并授权后可再次扫描这些文件。

锁屏和媒体通知默认显示正在播放的文件标题，可在系统通知设置中控制锁屏可见范围。

申请的其他权限用途：前台服务与唤醒锁维持用户启动的播放和音频处理；通知显示控制与任务进度；精确闹钟用于用户创建的定时播放；重启广播仅重新登记未来定时任务，不在开机时直接出声。

应用不申请麦克风、定位、通讯录、图片读取或管理全部文件的权限。

更名后仍保留原包名和导出目录。刷新会隐藏已失效或被系统回收的媒体；私有索引、显示别名和集合关系暂时保留，以便恢复授权或文件后继续使用，不会主动删除公共源文件。

V1.1 的 OCR 模型与字典随安装包提供，不下载模型，不发送识别数据；ONNX Runtime 遥测显式关闭。字幕文本、时间偏移与关联记录保存在应用私有数据库。带字幕导出使用用户通过系统目录选择器授权的本地目录，生成音频及同名 SRT；这些公共文件卸载后仍会保留。字幕页入口通知不含字幕正文。用户主动进入纯播放页后，字幕可出现在系统锁屏之上；退出页面不停止后台播放。
