# 静听 V0.3 实施与验收计划

在 V0.2 上覆盖升级，不删除集合或已有导出。六项反馈全部纳入本版：

| 需求 | 实现 | 必须验证 |
|---|---|---|
| 点击顺序 1、2、3 | 媒体库、集合、添加文件面板都使用有序选择；取消后序号连续，重选排在末尾；播放、添加、拼接沿用此顺序；集合可把所选按序移到最前 | 反向选取、取消重选、筛选切换、实际输出顺序 |
| 深入页面颜色／图标一致 | 全面覆盖主题色角色，统一弹窗、菜单、播放器、任务编辑；用项目内手写矢量图标替换旧 Material 图标，保留来源说明 | 主要弹窗与页面截图；主题角色检查；图标源码与许可 |
| 视频直接拼接音频 | 多选视频或音视频混合直接提交一次拼接，内部只处理音轨 | 不先导出中间文件，真实设备回读只有音频且顺序正确 |
| 单项与批量操作一致 | 批量播放、加入集合、逐项改名、分别提取／导出、集合内移除；多选另有拼接；名称仅改静听显示名 | UI 完整路径、每项独立结果、源文件完整 |
| 定时统一 | 统一任务编辑器：定时任务设置开始时刻／星期；计时任务立即播放、经过时长停止；两者均选择当前队列或集合、播放方式与停止时长。用户明确本版不需要倒计时后再开始 | 两入口共用状态、开始/修改/取消、后台到期、队列快照、重启规则 |
| 不牺牲音质的提速 | 兼容 AAC 音轨直接复制压缩包；同采样率的其他可解码音轨可无再次有损编码地输出 WAV；不能无损直接合并的输入提前提示，用户明确选择兼容 AAC 重编码 | AAC 压缩包哈希一致、PCM/左右声道与顺序、旧／新路径速度实测、取消及异常恢复 |

默认选择原音质路径。不同采样率的单一输出不能一边改采样率、一边宣称原始样本完全不变；用户确认的 AAC 转码必须明确标为重新编码。视频拼接不要求用户逐个预先提取。

计时任务按实际经过时间运行，暂停期间继续计时；设备重启取消。定时任务沿用当地时间精确闹钟、五分钟容差、冲突策略和不补播规则。任务页面与播放器显示、修改同一计时状态。

交付：0.3.0 可覆盖安装 APK、源码、图标来源说明、导出性能和质量验证记录、逐项验收报告。真机与模拟器验证范围分别说明。
